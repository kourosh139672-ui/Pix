# ادامه ساخت بازی فقط با GitHub

برای ادامه کار روی گوشی هیچ ویرایشگر یا موتور بازی نصب نمی‌کنیم. فایل‌های پروژه در همین مخزن نگهداری و از طریق GitHub به‌روزرسانی می‌شوند.

## اجرای ابری

فایل گردش‌کار در مسیر زیر قرار دارد:

`.github/workflows/tom-jerry-godot-web.yml`

پس از هر تغییر در پوشه `TomJerryGodot`، GitHub Actions روی سرور ابری پروژه را برای مرورگر خروجی می‌گیرد. هدف این است که بازی از طریق مرورگر گوشی باز شود؛ بنابراین برای اجرای نسخه وب، نصب برنامه بازی‌سازی لازم نیست.

## نکته درباره وضعیت

- فایل‌های پروژه و تنظیمات خروجی وب ثبت شده‌اند.
- گردش‌کار باید در GitHub Actions اجرا شود تا خروجی واقعی تولید شود.
- برای انتشار خودکار، قابلیت GitHub Pages مخزن باید در تنظیمات Pages اجازه انتشار با GitHub Actions داشته باشد.
- تا وقتی اجرای گردش‌کار موفق نشده و صفحه Pages منتشر نشده، لینک بازی آماده نیست.
- خروجی وب با APK اندروید فرق دارد؛ این مسیر برای بازی‌کردن در مرورگر است.
