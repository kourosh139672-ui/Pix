# Droidify

اپلیکیشن وب کشف موسیقی با رابط فارسی و راست‌چین، بدون نیاز به API Key.

## اجرا
فایل `index.html` را با یک وب‌سرور ساده باز کنید (برای نمونه GitHub Pages). برای درخواست‌های شبکه‌ای بهتر است از HTTPS استفاده شود.

## امکانات
- جست‌وجوی آهنگ و هنرمند
- نمایش کاور، نام آهنگ، خواننده و آلبوم
- پخش پیش‌نمایش رسمی در صورت موجود بودن
- لینک صفحه آهنگ در Apple Music / iTunes
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## منبع داده
از Apple iTunes Search API استفاده شده است:
`https://itunes.apple.com/search`

هیچ API Key یا حساب کاربری لازم نیست. این پروژه سرویس استریم کامل نیست؛ فقط پیش‌نمایش‌هایی را پخش می‌کند که API برای آن‌ها `previewUrl` برمی‌گرداند. دسترسی و موجودی آهنگ‌ها بسته به کشور و کاتالوگ Apple متفاوت است.

## فایل‌ها
- `index.html`: ساختار صفحه
- `styles.css`: ظاهر و چیدمان
- `app.js`: جست‌وجو و پخش پیش‌نمایش
