# PixPhone S100 target

S100 is currently a project codename and a hypothetical target device, not a verified hardware model.

## Prototype stage
- Android application prototype using Kotlin.
- Demonstrates a minimal PixPhone screen.
- Not a ROM, firmware, or bootable OS.
- No hardware-specific kernel, vendor blobs, device tree, or recovery image is included.

## Next prerequisites for a real ROM
1. Identify the actual target hardware and chipset.
2. Verify unlockable bootloader and development support.
3. Obtain compatible device tree, kernel sources, and vendor components.
4. Select and build a compatible AOSP base.
5. Test only on supported hardware with recovery and backup plans.
