# PixAI

پروژهٔ آزمایشی برای ساخت دستیار هوش مصنوعی فارسی.

## هدف
- شروع از یک مدل پایهٔ چندزبانه و سازگار با فارسی
- آزمایش و بهبود پاسخ‌گویی فارسی
- اجرای آزمایش‌ها با Google Colab از طریق مرورگر گوشی
- توسعهٔ رابط وب و سپس نسخهٔ اندروید

## نکته دربارهٔ اندازهٔ مدل
ادامهٔ آموزش (continued training) تعداد پارامترهای مدل پایه را افزایش نمی‌دهد. ابتدا مدل پایه و محدودیت منابع رایگان را ارزیابی می‌کنیم؛ هدف یک میلیارد پارامتر، اندازهٔ نهایی مدلی است که باید جداگانه انتخاب شود.

## وضعیت فعلی
مرحلهٔ صفر: آماده‌سازی مخزن و آزمایش اجرای مدل پایه.

## ساختار
- `src/`: کدهای پروژه
- `notebooks/`: آزمایش‌های Google Colab
- `data/README.md`: راهنمای داده‌ها؛ فایل‌های دادهٔ حجیم در Git قرار نمی‌گیرند.
